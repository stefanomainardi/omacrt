Green is the default because it is the launcher's own phosphor green and the colour the diagnostics print in. Paper is for a row of logos where green would shout. The light ground is for print and for anywhere the mark sits on white; the knockout is for a badge. There is no other lock-up colour, and the mark never carries an effect: everything on this sheet that is grey is a mistake drawn on purpose.
