# The Flyback diagrams

Two artboards, both generated by [`gen.py`](gen.py) rather than drawn, so that
a number cannot drift away from the measurement it came from.

| | |
| --- | --- |
| `Main.dc.html` | the architecture: the desktop and the lease on one side, the compositor's own parts in the middle, the kernel, the converter and the tube on the other |
| `Frame.dc.html` | one frame at 16.655 ms, drawn to scale, twice: with a deadline and without one |

Regenerate with `python3 gen.py` from this directory, then seed them onto a
canvas with the `/design` skill in Claude Code.

Everything on the architecture sheet names a real component in
`shell/src/bin/flyback/`. Everything on the frame sheet is a measured
percentile from the compositor's own trace, except the callback and commit
marks, which are arithmetic from the scheduler's estimates and are drawn
lighter and labelled as such in the footnote.
